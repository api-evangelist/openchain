TomorrowX has announced an OpenChain ISO/IEC 5230:2020 conformant program. “Our customers and partners run the Composable Agentic Platform in regulated and mission-critical environments, where certainty about the software supply chain is not optional,” says Kostas Siourthas, CEO of TomorrowX. “Self-certifying our open source licence compliance program to ISO/IEC 5230 formalises practices already built into every CAP release — generated LICENSE and NOTICE attribution, verbatim licence texts, a complete CycloneDX Software Bill of Materials, and a public source offer for LGPL components.
