The Agent Passport System (APS) has joined the OpenChain Community of Conformance, self-certifying to ISO/IEC 5230:2020 for open source license compliance and ISO/IEC 18974:2023 for open source security assurance. APS is an open protocol for governing what AI agents do. It provides AI agents with a verifiable identity, links that identity to the person or organization the agent represents, and generates signed evidence for every action performed under that authority.
